## Project Overview

ASACS (Automatic Student Academic Calendar System) is a web-based
academic scheduling system that connects students, instructors,
and academic departments.

The system allows students to subscribe to a personalized academic
calendar that automatically synchronizes assessment dates and updates
with Google Calendar or Apple Calendar.

also it supports instructors and academic departments in
coordinating assessment schedules, detecting scheduling conflicts,
and recommending suitable exam dates based on student workload
and course difficulty
