## Project Overview

ASACS (Automatic Student Academic Calendar System) is a web-based system that helps university students manage academic deadlines by synchronizing course assessments with personal calendar applications such as Google Calendar and Apple Calendar.

The system also supports instructors and academic departments in managing assessment schedules and identifying scheduling conflicts.
